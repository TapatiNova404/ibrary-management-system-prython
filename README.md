# 📚 Library Management System

A menu-driven **Library Management System** developed using **Python**. This project helps manage library records such as adding, updating, deleting, searching, issuing, and returning books. The data is stored permanently using **JSON file handling**, making it simple, lightweight, and easy to maintain.

---

## 📌 Features

- 🔐 Admin Login
- ➕ Add New Book
- 📖 View All Books
- 🔍 Search Book by ID or Title
- ✏️ Update Book Details
- ❌ Delete Book
- 📕 Issue Book
- 📗 Return Book
- 📊 Library Statistics
- 💾 JSON-based Data Storage
- ✅ Input Validation
- ⚠️ Exception Handling
